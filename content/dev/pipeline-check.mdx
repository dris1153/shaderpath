# Pipeline check

Inline math: $\mathbf{v} \cdot \mathbf{w} = \|\mathbf{v}\|\,\|\mathbf{w}\|\cos\theta$ — and a display block:

$$
\mathbf{p}_{clip} = P \, V \, M \, \mathbf{p}_{model}
$$

A GLSL block highlighted by shiki in both themes:

```glsl
precision highp float;
uniform float uTime;
uniform vec2 uResolution;

void main() {
  vec2 uv = gl_FragCoord.xy / uResolution;
  vec3 c = 0.5 + 0.5 * cos(uTime + uv.xyx + vec3(0.0, 2.0, 4.0));
  gl_FragColor = vec4(c, 1.0);
}
```

<Callout variant="mistake" title="Lỗi hay gặp">
  Quên `normalize()` vector trước khi `dot()` — kết quả không còn là cosine của
  góc nữa.
</Callout>

| Hàm | Ý nghĩa |
| --- | --- |
| `mix(a, b, t)` | nội suy tuyến tính |
| `smoothstep(e0, e1, x)` | nội suy Hermite có kẹp biên |
