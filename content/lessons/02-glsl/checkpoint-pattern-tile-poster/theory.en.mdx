## Goal

The GLSL track's closing mini-build: construct a working, fullscreen tiled poster that synthesizes every technique from this module — SDFs, tiling, matrix transforms and self-debugging by color — instead of practicing them in isolation.

## Requirements

The fragment shader draws an even grid (tiling via `fract`/`floor`), where each cell shows one of **at least 2 distinct SDF motifs** (e.g. a circle and a rounded box) chosen by cell-id; each cell **spins on its own with `uTime`** via a `mat2` built with the correct column constructor; the whole scene carries a **global gradient tint**; every motif's edge is **anti-aliased with `smoothstep`**, no jagged pixels. Full details live in the Exercises section below.

## Structure Hint

Four steps, in order: (1) tile UV into a grid, getting `cellId = floor(uv * N)` and local coordinates `cellUv = fract(uv * N) - 0.5`; (2) use `cellId` to pick a motif (even/odd parity or a hash); (3) rotate `cellUv` with `rotate2d(uTime + offset)` — the offset comes from hashing `cellId` so cells desync from each other; (4) compute the SDF, turn it into a mask with `smoothstep`, blend in the gradient tint, then composite onto the background.

## What "Done" Looks Like

Check against the checklist in the exercises section before opening the solution — self-debug with the output-value-as-color technique from the previous lesson if a cell looks wrong, instead of guessing.
